# 人味守卫 · 消息质检与打回改写（astrbot_plugin_humanize_guard）

拦截 AI 即将发出的回复做质检，命中即打回并按检测项注入提示词改写，复检通过才真正发出，让文案更像真人随手打的字。

**版本**：v1.0.0 ｜ **适用**：AstrBot >=4.5,<5 ｜ **依赖**：无第三方库

## 功能

- **发出前质检**：截获待发送的 AI 回复，指令与面板输出等非 LLM 轮次直接放行。
- **命中打回**：命中任一项即打回，按命中的检测项拼装改写提示词注入请求，督促模型重写。
- **复检通过才发出**：改写稿默认只过规则层复检，通过后才写回消息链；轮数到上限发最后一版，绝不吞消息。
- **本地公式修复优先**：句末句号、连发标点、残留字符、Markdown 排版、缺标点断句等由确定性规则直接改好，零模型调用。
- **规则层 + AI 层**：代码判定为主，AI 层负责整体 AI 味等模型裁决，可单独关闭。
- **检测项可自定义**：内置检测项可勾选、调阈值、改注入词，也可新建自定义项与改写提示词。
- **标签剥离后加回**：好感度等标签检测时剥离、不参与比对，改写完成后按原顺序加回。
- **分段插件共存**：与「对话分段Pro」等配合，主动消息先按整条质检，分段碎片不重复质检。

## 质检流程

1. 截获待发回复，剥离好感度等标签得到裸文本。
2. 规则层逐项判定，毫秒级、零成本。
3. 能由本地公式修好的问题直接改好，修干净就发出，不调用模型。
4. 修不掉的交给 AI 层裁决，命中则按检测项拼提示词打回改写。
5. 改写稿再走本地公式与复检，默认最多 2 轮；通过后加回标签发出并记入本会话历史。
6. 超时、异常或改写失败时发原稿或最后一版，绝不吞消息。

## 检测项

内置 16 项检测，全部可在面板勾选、调参；其中 12 项支持本地公式修复，4 项交给 AI。

- **标点与残留**：句中缺标点、句末句号、标点/表情异常、残留标记。
- **重复类**：与上一句重合、本条内部重复、相同开头、相同结尾、口头禅超频。
- **文风类**：AI 套话、结构化排版、书面语与翻译腔、AI 身份泄漏、整体 AI 味。
- **其他**：复述用户原话、单条过长。

勾选任何一项都会改变检测模型的注入词，面板可实时预览拼装结果。

## 安装

1. 将插件目录 `astrbot_plugin_humanize_guard` 放入 AstrBot 的 `data/plugins/`。
2. 在管理面板「插件」页重载插件，或重启 AstrBot。
3. 无第三方依赖，无需额外安装。

## 配置

在面板「插件设置」页修改，以下为常调项：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 总开关 | 开 | 关闭后不检测、不打回、不注入 |
| 启用规则层 | 开 | 代码判定，毫秒级零成本 |
| 启用 AI 检测层 | 开 | 模型裁决，每条回复 +1 次调用 |
| 短消息放行阈值 | 4 字 | 短于该字数的回复直接放行 |
| 本地公式修复 | 开 | 规则能改好的问题不再调用模型 |
| 最多打回改写轮数 | 2 | 到上限发最后一版，不会吞消息 |
| 体检模式 | 关 | 只检测记录，不改写、原稿照发 |
| 检测与改写模型 | 跟随会话 | 可指定 Provider，建议便宜快的模型；单次调用超时 12 秒 |
| 分段插件兼容 | 开 | 主动发送先整条质检、碎片去重 |
| 详细日志 | 关 | 打印裁决与注入词，排查误杀 |

黑白名单、下轮反馈注入、历史条数、额外标签正则等可在设置页继续调整。

## 使用

### 指令

```
/qc 状态          查看开关与统计（别名：/质检、/人味质检）
/qc 测试 <文本>    试跑检测，显示命中项与 AI 层原始输出，不改写不发送
/qc 日志 [条数]    查看最近的打回记录
/qc 帮助
```

### 面板

- **设置**：总开关、检测与改写模型、打回改写、黑白名单等参数。
- **检测项**：勾选参与检测的项目、调阈值、新建自定义项，编辑检测注入词与打回改写提示词，可预览注入词。
- **打回日志**：最近的打回记录，与 `/qc 日志` 同源。

### 黑白名单

- **黑名单（免检）**：名单内的会话/用户永不质检，原样放行。
- **白名单模式**：开启后只质检白名单内的会话，其余放行；黑名单优先。
- 条目每行一个，支持完整会话 ID、群号、发送者 ID；开启 AstrBot「唯一会话」时写裸群号也能命中。

## 注意事项

- 适用 AstrBot >=4.5,<5；与同样挂在回复装饰钩子上的插件可共存。
- 开启 AI 层后每条回复多 1 次模型调用，违规时再增加 0~2 次；可关 AI 层、用白名单或换便宜模型降低开销。
- 检测或改写超时、解析失败一律放行原稿，规则层结果不受影响。
- 本地公式修复偏保守：补丁须“违规变少且不新增”才采纳，偶尔能修但没修会交给 AI。
- 数据保存在 `data/plugin_data/astrbot_plugin_humanize_guard/`，只记录最终发出的版本，改写草稿不进历史。
